# Characterizing key agents in the cryptocurrency economy through blockchain transaction analysis

- 作者：EPJ Data Science 论文
- 年份：2021
- 稳定来源：https://link.springer.com/article/10.1140/epjds/s13688-021-00276-9
- 访问日期：2026-07-25

## 与本项目的关系

研究使用交易量、时间节奏和交易网络结构等特征刻画链上经济代理，支持建立角色假设和行为聚类。

## 限制

行为特征不能直接映射到现实世界身份；项目必须提供 unknown/mixed 角色、隐私边界和样本外验证。
